Chapter 2: Structural Containers and Lists

1. Block vs Inline Elements

I am a <div> (Block): I take up the whole width from left to right!
I am another <div> (Block): I am forced to start on a new line because the div above took all the space.

In this paragraph, the word <span> is inline, so it stays inside the sentence without breaking to a new line!

2. Unordered List (<ul>)

Used when the order of items does NOT matter (bullet points):

  • HTML5
  • CSS3
  • JavaScript

3. Ordered List (<ol>)

Used when the order DOES matter (1, 2, 3...):

  1. Step 1: Write HTML
  2. Step 2: Add CSS Styling
  3. Step 3: Add JavaScript Logic

Special attributes for <ol>:

Using letters (type="A"):

  1. Frontend Development
  2. Backend Development
  3. Database Management

Using Roman numerals (type="I"):

  1. Phase One
  2. Phase Two
  3. Phase Three

Starting at number 10 (start="10"):

  1. Item 10
  2. Item 11

4. Description List (<dl>)

Used for terms and their definitions (like a dictionary or FAQ):

HTML
HyperText Markup Language - defines the structure of web pages.
CSS
Cascading Style Sheets - defines the style and appearance of web pages.
JavaScript
Programming language that adds interactivity and logic to web pages.
